Privacy Policy
Last updated April 2026 · Drift v1.2.0

Data Collection

Drift records which websites you visit and how long you spend on each page. This data includes URLs, page titles, timestamps, and duration. No page content, form inputs, passwords, or personal information is collected.

Data Storage

All data is stored locally on your device using the Chrome storage API. When you sign in, session history can optionally sync to Supabase cloud storage for cross-device access. Cloud data is encrypted in transit and isolated per user.

Data Sharing

Drift does not transmit any data to any third party. There are no analytics, no telemetry, no tracking pixels, and no advertising. Your data stays on your device unless you opt into cloud sync.

Data Deletion

You can delete all stored data at any time from the Drift dashboard. Uninstalling the extension removes all local data. Cloud-synced data can be deleted by signing out and requesting account deletion.

Permissions

tabs — Required to detect which tab is active and read page URLs for session tracking.

activeTab — Required to access the current tab's information.

storage — Required to save browsing events locally on your device.

idle — Required to detect when you step away, so sessions are properly ended.

identity — Required for Google OAuth sign-in for optional cloud sync.

notifications — Required to send drift detection alerts.

Authentication

Drift supports optional sign-in via Google OAuth or magic link email. Authentication is handled by Supabase. No passwords are stored by Drift. Sign-in is entirely optional — all features work without an account.

Contact

Questions about this policy can be directed to the project repository on GitHub.
